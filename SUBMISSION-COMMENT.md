For **The Compression Paradox**, I built a specialist folder for a fictional company’s purchasing policies: on seven freshly rerun questions, it beat no folder 70–10, but the policy documents alone also scored 70. I didn’t have a human available to write the additional challenge questions, so I used a separate Claude session given only the source documents—disclosed AI authorship, not independent human testing—and on that set the documents beat the folder 80–77. The surprise was that the folder treated an ambiguous policy as settled while the documents-only answer covered both readings; all raw transcripts, scores, question-selection history and reproduction instructions are in the repo.

The Compression Paradox is a specialist folder for fictional purchasing policies: in actual Claude Projects tests it beat no folder 64–13, while the primary documents alone scored 70. The surprising line is that the added architecture showed no accuracy benefit: six ties and one loss for declining to confirm historical approval timing; accepting that disclosed grading judgment differently would make all seven ties. The repo preserves raw UI captures, earlier CLI tests and a separate-session Claude-authored challenge where sources beat the folder 80–77, with the authorship, grading and question-selection limits stated openly.

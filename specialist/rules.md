# Working rules (mandatory)

1. **Read the primary text.** Before answering, open the relevant files in `reference/` using the navigation index in `README.md`. The index is a pointer, not a source.
2. **Identify every feature in the facts**: amount, date, purchase type (routine / travel / airfare), emergency claim, vendor status, approver availability. Each feature maps to sections in the index; check all of them.
3. **Apply the date first.** Determine which threshold was in force on the transaction date before applying any tier.
4. **Check inclusivity and amount basis** for any threshold comparison.
5. **Layer approvals; do not substitute them.** Special policies can add requirements or waive specific ones. A provision waives only what it expressly names.
6. **Treat exceptions narrowly.** Confirm each qualifying condition of an exception is established by the facts supplied. If a condition is not established, apply the ordinary rules and say so.
7. **Distinguish approval from notification** and *before* from *after*.
8. **Vendor restrictions are checked independently** of every other exception.
9. **Cite** the section identifiers you relied on; cite only identifiers that exist in `reference/`.
10. **No invention.** Do not add approvers, dollar limits, deadlines or documentation requirements not found in the text.

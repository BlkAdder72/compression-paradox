# Unseen-question protocol and executable challenge kit

Status: external author NOT accessible in this repair. No external invitation, authorship, independent review, fresh Claude run or score is claimed. The bundled G1-G4 questions were generated by Codex after repository review and are explicitly NOT independent. They are unexecuted challenge materials. H1-H8 are also post-analysis challenges, not independent holdouts.

## Independent route when an external author becomes available

1. Freeze the treatment revision. Give a genuinely external author only the six `fixture/` documents, their hashes, and a neutral request for checkable boundary/cross-policy questions. Do not supply specialist files, existing questions, outputs, or results. Record their identity, relationship/conflicts, date, and exactly what they saw. A fresh agent from the same repair is not an external author.
2. Ask the author to deliver a JSON file using `generated-questions.json`'s schema: unique safe `id`, `prompt`, `gold`, and `critical_requirements`. Require a truthful provenance statement. Keep the answer key with the evaluator, outside every model session. Human review must verify each answer against primary sections before runs.
3. Commit and hash the author file, rubric, fixture and frozen treatment before execution. Record the commit and timestamp. Do not tune the specialist after seeing questions. If it is changed, invalidate unseen status for that revision and obtain new questions.
4. Run at least A/B/C with the same pinned available model, CLI and flags. A tests source availability; B/C tests incremental structure. Counterbalance order across repetitions, predeclare all run IDs and report all attempts and exclusions. D/E can use the same protocol for the summary comparison. The runner passes only the `prompt` field, never gold answers, to Claude.
5. Commit unedited captures before scoring. Produce a shuffled assessor packet using `scripts/prepare_blind.py`. Keep its mapping hidden from assessors. Use the frozen rubric; for N questions the maximum is 10N. Score material omitted approvals as wrong conclusions with the existing cap of 4. Record critical omissions and false authorizations for every item. Prefer two assessors, disclose their identity/family/conflicts and adjudicate disagreements without silently changing the rubric.
6. Report per-question scores, totals, wins/ties/losses, exclusions, source-read violations, provenance and uncertainty. Independent authorship and model provenance require external evidence; scripts cannot certify either.

## Run the supplied generated questions (not independent)

From a clean committed repository with an authenticated Claude CLI, choose never-used run IDs and absolute sibling output/workspace directories. On Windows, forward-slash paths work with Python:

```text
python scripts/run_trials.py --arm B --suite challenge --questions evaluation/challenge/generated-questions.json --run-id B_G_NEW1 --workspace C:/paradox-sessions --output C:/paradox-captures --dry-run
python scripts/run_trials.py --arm A --suite challenge --questions evaluation/challenge/generated-questions.json --run-id A_G_NEW1 --workspace C:/paradox-sessions --output C:/paradox-captures
python scripts/run_trials.py --arm B --suite challenge --questions evaluation/challenge/generated-questions.json --run-id B_G_NEW1 --workspace C:/paradox-sessions --output C:/paradox-captures
python scripts/run_trials.py --arm C --suite challenge --questions evaluation/challenge/generated-questions.json --run-id C_G_NEW1 --workspace C:/paradox-sessions --output C:/paradox-captures
python scripts/prepare_blind.py --questions evaluation/challenge/generated-questions.json --run A=C:/paradox-captures/A_G_NEW1 --run B=C:/paradox-captures/B_G_NEW1 --run C=C:/paradox-captures/C_G_NEW1 --output C:/paradox-grading/G_NEW1
```

Replace paths on macOS/Linux with absolute local paths. Replace the question file with the externally authored committed file for the independent route. Dry-run output is only a plan and must never be represented as model evidence. Keep `mapping.json` from assessors; share `packet.md` and rubric only. Raw responses may reveal arms; record this unavoidable blinding limitation. The packet's response text is copied from terminal result records; raw streams remain the authority.
